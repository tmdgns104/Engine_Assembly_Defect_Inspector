# WINDOWS-CAPTURE-002 — 제품별 안내 촬영

Status: DONE / VERIFIED (소프트웨어)

## 문제와 범위

사람이 조명·각도 변화의 영향을 고려해 촬영하려면, 앱이 실제 배치와 품질 확인 순서를 안내해야 한다.
기존 Windows 수집 도구에 제품 설정 기반 안내를 추가한다. Runtime/Detector 구조 변경은 없다.
기존 저장기·verifier·프로필·manifest v1/v2를 재사용하며 수동 촬영도 유지한다.

## 수용 조건

- 제품별 안내 설정과 공통 기본 안내. 카메라는 고정하고 실제 사용 범위의 조명/물체 위치 변화를 안내한다.
- 선택한 조건에서 제품의 모든 상태를 한 번씩 확인하는 소규모 라운드. 학습 충분 수량이라는 주장은 없다.
- 조건별 새 session, 상태 변경별 episode. 사람이 준비 확인 → 한 장 저장 → 원본 품질 검토 후 다음 상태.
- 준비 이전/오래된 프레임, 중복 저장, 검토 전 다음 단계 진행 차단. 재촬영은 원본과 거절 기록을 보존한다.
- 버전 있는 별도 안내 사본/해시와 사람 검토 기록. 재개 시 기존 verifier로 기록을 확인하고 미검토 사진을 복원한다.
- 저장 또는 검토 기록 실패 시 성공/진행을 과장하지 않으며 복구 위치를 표시한다.
- 추가 자동 테스트와 실제 창 확인. 실제 물체 배치/추가 촬영은 사용자 실행 대기로 구분한다.
- 원래 92개 테스트와 실제 네 장 및 CAD 작업을 보존. Jetson/학습/라벨링/전역 Skill 변경 없음. T05 TODO 유지.

## 구현 방향

`training/capture_windows/guide.py`는 제품별 안내 및 사람 검토의 상태를 관리한다.
`app.py`는 같은 카메라/저장 경로에 안내 패널을 연결한다. 안내는 결정적인 설정 기반이며 AI 판정이 아니다.
`capture-guide.json` 제품 안내는 정답 profile.json과 분리하고, session 안에 사본을 보존한다.
이미지 저장을 복제하지 않고 CollectionSession.save / verify_session을 그대로 사용한다.
