# 요청 전 미리보기 추적 재연결

2026-10-15 TASK-022의 실제 재시험을 위한 최소 수정이다.

검사에 아직 사용하지 않은 모형을 옮기면 Tracker가
`WAIT_AREA_CLEAR / TRACK_ASSOCIATION_INVALID`에 머물 수 있었다.
기존 `_release_unused_preview()`는 관측 누락으로 잃은 미리보기만
새 관측으로 대체하여, 위치 변경으로 잃은 미리보기는 복구하지 못했다.

같은 함수가 위 두 추적 실패를 처리하게 한다. 접수한 PLC 요청,
진행 중 검사, 이전 검사 제품 문맥이 없는 미사용 미리보기에만 적용한다.
신선한 연결, Request LOW, 출력 0, 기존 다음 제품 분리 조건을 유지한다.
새 관측을 요구하며 제품 이탈/CLEAR를 생성하거나 요청 중 제품을 바꾸지 않는다.
모델·조립 정렬·PLC·통신 시간 제한은 변경하지 않는다.

새 테스트로 위치 변경 후 최초 요청 접수, 요청 접수 후 교체 금지,
통신이 오래되거나 끊긴 경우 재연결 금지를 검증했다.
수정 전 신규 위치 변경 테스트 실패, 수정 후 관련 87개 회귀 통과.
원본 로그는 노트북의 `runs/assembly_ai_022/input_recovery/`에 보존한다.

사용자가 이송 4.5초를 적용한 뒤 실시한 직전 검사는
`NO_VALID_CURRENT_PRODUCT_AT_PLC_REQUEST`이며 촬영 원본 0장이다.
요청 당시 프레임별 추적 기록은 남아 있지 않아 위 결함을 그 실패의
유일한 원인이라고 단정하지 않는다. 조립 입력 복구와 현장 PASS/FAIL은
별도 미완료 사항이다. 실제 적용과 재시험 결과는 이후 현장 기록에 남긴다.
