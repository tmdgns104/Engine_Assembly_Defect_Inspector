# HARDWARE-CAD-002 학습 기록

## 무엇을 했는가
Conveyor에 물리는 V2를 보존하고 작업대에 나사로 고정하는 별도 V3 Portal을 만들었다. 사용자 후속 선택에 따라300 mm 일체형 기둥2개, Deck 지지면150~300 mm를15 mm씩 조절하는 구조다. Tilt를 없애고 camera를 얕은 Deck pocket 위에 수직 하향으로 놓는다.

## 왜 Hole Rail을 쓰는가
실제 conveyor belt의 작업대 기준 높이를 아직 모른다. 고정 높이 하나를 정하면 초점이나 시야가 맞지 않을 수 있다. 여러 구멍을 만들어 실물을 받은 뒤 적절한 높이를 선택하도록 했다. Fixed focus camera는 초점을 돌리는 대신 camera와 대상 사이 거리를 조절해 적합한 화면을 찾아야 한다.

## Slot과 Hole의 차이
긴 Slot은 연속으로 움직일 수 있지만 조인 위치를 다시 찾고 미끄러짐을 막아야 한다. Hole은15 mm 간격으로만 움직이지만 같은 index를 선택하면 위치를 다시 찾기 쉽다. 이 간격이 높이 조절 해상도다. 양쪽에 같은 index를 사용하고 한쪽 두 bolt를45 mm 떨어뜨려 Crossbar 회전을 줄인다.

## 왜 높이 기준을 먼저 정했는가
기둥 길이, 전체 장치 높이, Deck 지지면, Lens 높이는 서로 다르다. 사용자는 최대300 mm를 **작업대→Deck 지지면**으로 확정했다. 기둥 자체300 mm는 Base 위에 올라가며 상단이310 mm가 된다. Pad와 렌즈 돌출, belt 높이를 더 측정해야 실제 촬영 거리를 계산할 수 있다.

## Lens Window를 Coupon으로 확인하는 이유
자의 원근이 있는 사진은 정밀 측정값이 아니다. Ring22 mm와 중심0은 추정값, Window30 mm는 시험 시작값이다. 실제 pocket·land·stop을 보존한 Coupon에 camera를 올려 body fit, ring 접촉, stand/strap 간섭을 확인한다. 중심이 다르면 offset을 고치고, 구멍만 크게 만들어 문제를 숨기지 않는다.

## 무엇을 관찰했는가
개별 STL의 닫힌 표면뿐 아니라 실제 mesh에서 구멍 중심·간격·내부 치수를 읽어야 한다. Deck의 side/rear stop이 한 선에서만 닿으면 비정상 mesh가 생길 수 있어 간격을 두어 수정했다. Source를 고친 뒤 다시 export하며 이전 PASS를 새 모델의 결과로 쓰지 않는다. 최종 실행 수치는 V3의 validation JSON을 기준으로 한다.

최종 새 빌드에서 STL 8개, 150~300 mm의 높이11단계, 33개 배치의 경계 검사924건과 상세 교차 검사6건이 통과했다. 검증기가 단순히 PASS만 내는지 확인하기 위해 메모리에서 구멍 하나의 중심을1 mm 옮겼으며, 이때 치수 검사가 FAIL을 냈다. 원본 STL은 바꾸지 않았다.

## 결과가 의미하는 것
Digital CAD 검사는 형상과 지정한 reference 사이 간섭을 확인한다. 실제 출력 품질, 나사 fit, 하중, 진동, PETG의 장기 변형, 초점/FOV는 아직 검증하지 않았다. 300 mm 일체형 rail은220급 bed에 안 들어가므로 실제 printer 배치도 확인해야 한다.

## V1에서 어떻게 재사용하는가
검사 대상이 바뀌어도 같은 hole index·Deck 위치·높이 기준을 기록해 촬영 조건을 재현할 수 있다. 실제 엔진 치수나 필요한 촬영 높이는 현재 가정하지 않는다. Coupon → 측정 → parameter 수정 → 재export/검증 순서를 다시 사용한다.
