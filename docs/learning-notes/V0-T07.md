# V0-T07 — 첫 Windows GPU baseline

- What I did: 승인된 train120/val60으로 YOLOv8n을 RTX5070 Laptop에서100epoch 한 번 학습했다.640/batch16/seed42/AdamW lr0.001/FP32, workers0, 고정 증강을 사용했다.
- Why I did it: COCO8 smoke는 환경 확인만 한다. 실제 제품 데이터에서 최초 기준 성능과 재현 가능한 설정·모델·검증 근거가 필요했다. L/R 물리 클래스의 모양을 반전시키지 않도록 flip0, 제한된 회전/이동/크기/색 증강을 선택했다.
- What changed: 제품 경로와 클래스는 YAML/schema로 분리하고 공통 구성·학습·평가 스크립트를 추가했다. best/last,100epoch CSV,전체 로그,60개 B03 예측과 입력 해시를 보존했다.
- What I observed: exit0, cuda:0 실제 학습, best/last GPU 재로드. 총313.42초(초기화·최종 검증 포함),epoch loop300.78초. P0.99815/R1.0/mAP50 0.995/mAP50-95 0.83350. conf0.25·IoU0.5에서TP120/FP0/FN0. stricter IoU AP는 낮아 사각형 위치 개선 여지는 있다.0002 R IoU0.759,0055 L IoU0.774 예측 이미지를 보조 확인했다.
- What this means for V1: 입력 schema/데이터 경로를 엔진 제품으로 교체하고 같은 절차를 재사용할 수 있다. 현재 작은 한 검증 그룹의 결과는 새로운 제품·환경의 성능을 보장하지 않는다. 실제 추론 shape은640설정의 직사각 letterbox384×640일 수 있어 측정 설정을 함께 읽어야 한다.
- Decision if retraining is needed: 이번 기준은 보존한다. 자동 튜닝은 하지 않았다. 추가 데이터/튜닝이 필요하면 별도 이유와 실험 버전으로 진행하고 B04 최종 Test는 모델 선택 후 남긴다. Jetson·정상/불량 판단·DB 저장은 아직 별개 작업이다.
