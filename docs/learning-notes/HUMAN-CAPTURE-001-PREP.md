# 설정을 바꿔도 과거 촬영 의미 유지하기

이어폰 제품의 상태를 JSON으로 정의하고 기존 수집/검증기를 재사용했다. 제품명과
제거 대상을 코드에 넣으면 제품을 바꿀 때 수집 코드와 과거 기록의 해석이 함께 바뀔 수 있다.
그래서 v1을 보존하고 v2 행에 설정 사본과 정규 JSON 해시를 넣었다.

원본 설정을 수정·삭제해도 기존 기록이 검증되는지, 사본 변경은 거부되는지 확인했다.
가상 네 부품 제품도 공통 코드 변경 없이 저장·검증했다. 전체 56개 테스트 결과는
[Evidence](../verification/HUMAN-CAPTURE-001-PREP.txt)에 있다. Windows 합성 테스트는 실제
배치나 사진 품질을 검증하지 않는다.

엔진 전환 때는 실제 부품·수집 상태를 새 profile로 정의한다. 정상 장착 판정과 임계치는
실물 사진과 Validation 근거로 별도 Recipe에 정하며, 촬영 시나리오를 추론의 정답 지름길로
전달하지 않는다. 이번에는 라벨링·split·학습을 하지 않아 재학습 판단도 아직 대상이 아니다.
