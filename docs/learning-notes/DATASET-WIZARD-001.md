# DATASET-WIZARD-001 학습 기록

## 무엇을 했는가

기존 Windows 촬영기에 전체 계획을 자동 안내하는 수집 길잡이를 추가했다. 사람이 최초 설치·배치를 하고 준비 버튼을 누르면 프로그램이 새 프레임 한 장을 저장/검증하고 다음 행동을 안내한다. 상태별 묶음 확인은 사람이 한 번 수행한다.

## 왜 했는가

처음 데이터를 모으는 사람이 조명·위치·방향·장수를 매번 기억하면 특정 상태에 특정 조명만 몰리기 쉽다. 프로그램은 회차 → 조명 → 배치 → 모든 상태 순서로 조건을 고르게 관리한다. 240/80장은 초기 계획이며 필요한 학습량이나 정확도 보장은 아니다.

## 무엇을 바꾸고 관찰했는가

카메라와 원본 저장기는 재사용하고 계획/준비/검토를 별도 버전 기록으로 연결했다. 전체 계획 모의 실행, 중복·연결 오류·재촬영·중단 복원, 실제 Tk 창을 확인했다. 합성 입력 검증은 실제 제품 배치 검증과 다르다. 기존 실물 네 장은 새 계획 실적에 넣지 않았다.

사진별 선명도 지표는 물체가 빠져 질감이 줄어도 낮아질 수 있다. 어두움·반사·유사도는 보조 경고로 두고 준비 시험 후 상태별 시작값을 고정한다. 지표가 좋아도 손 가림이나 L/R 정답을 자동 확정하지 않는다.

## 결과가 의미하는 것

파일 저장 성공, 품질 경고 확인, 실제 상태의 사람 확정은 서로 다른 사건이다. 사진 네 장이 디스크에 있어도 묶음 확인 전에는 검토 대기다. 저장 후 마지막 기록 전에 중단되면 원본/manifest로 연결을 복원하되 사람의 준비 상태를 복원하지 않는다.

같은 연속 촬영의 origin_group을 보존해 학습/시험 용도 혼합을 막는다. 다른 시간에 다시 준비했다는 사람 선언도 독립성의 자동 입증은 아니다. 실제 데이터 검토와 이후 그룹 분할이 필요하다.

## V1에서 어떻게 재사용하는가

제품별 부품·상태·완전한 배치 지시·조건 계획을 JSON으로 바꾸고 카메라/저장/검토/복구 흐름은 재사용한다. 엔진 실물이 없는 지금 실제 엔진 부품이나 box 좌표를 발명하지 않는다. 라벨링 인계는 원본 목록이며 모델 추론이 촬영 정답을 읽어 판정하지 않도록 분리한다.

## 재학습 판단

이번 작업은 촬영 프로그램 개발이다. 라벨링·분할·학습·평가를 실행하지 않았다. V0-T05는 TODO이며 새 길잡이의 실제 물체 촬영/품질 확인이 먼저다.
