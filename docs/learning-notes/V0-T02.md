# V0-T02 학습 기록

## 무엇을 했는가

Windows PC에서 이전에 성공한 COCO8 GPU smoke 학습 1회의 로그와 checkpoint를 확인했다. 이번에는 학습을 다시 실행하지 않고 환경 검증, `.gitignore` 수정, 결과 문서화를 마쳤다. Jetson은 사용하지 않았다.

## 왜 했는가

본격적인 데이터를 준비하기 전에 Python이 GPU를 사용할 수 있고 학습 결과를 저장할 수 있는지 확인하기 위해서다. **가상환경 `.venv`**는 프로젝트별 Python 패키지 보관 공간이다. 전역 Python과 분리하면 다른 프로젝트에서 사용하는 패키지를 바꾸지 않고 이 프로젝트에 필요한 버전을 유지할 수 있다.

이번 전역 Python에는 **CPU PyTorch `2.13.0+cpu`**, 프로젝트에는 **CUDA PyTorch `2.11.0+cu128`**이 있었다. CPU 버전은 CPU로 연산하고, CUDA 버전은 호환되는 NVIDIA GPU와 드라이버가 있으면 GPU로 연산할 수 있다. 따라서 같은 컴퓨터라도 어떤 Python 실행 파일을 사용하는지가 중요하다.

## 무엇을 관찰했는가

`.venv\Scripts\python.exe`에서 Python 3.13.5, CUDA 12.8, RTX 5070 Laptop GPU, Ultralytics 8.4.146을 확인했다. `torch.cuda.is_available()`은 **현재 Python 프로세스에서 PyTorch가 CUDA 장치를 사용할 수 있는지** 확인한다. `True`만으로 특정 학습이 GPU에서 실행됐다고 증명되지는 않는다. 기존 학습 로그의 `CUDA:0`와 `GPU_mem 0.207G`를 함께 확인했다.

GPU는 학습 중 많은 행렬·텐서 계산을 병렬로 처리한다. 모델 예측, 오차 계산에 따른 역전파, 가중치 갱신 등에 사용된다. 이번 smoke는 CPU와 속도를 비교한 실험이 아니므로 GPU가 몇 배 빠르다고 결론 내리지 않는다.

**Epoch**는 학습 데이터를 한 번 전체적으로 학습하는 단위다. COCO8 train 4장으로 1 epoch를 완료했다. 기존 래퍼 로그의 소요 시간은 약 17.97초이고, CSV의 epoch 누적 시간은 2.26436초다. 두 값은 측정 범위가 달라 같은 시간으로 취급하지 않는다.

**Checkpoint**는 학습한 모델 상태를 파일로 저장한 것이다. `best.pt`는 validation 기준으로 선택된 모델, `last.pt`는 마지막 저장 모델이다. 두 파일이 모두 존재했다. 다만 이번 로그는 optimizer가 제거되었다고 명시하므로, 이 파일이 학습 중단 지점을 모든 상태까지 똑같이 복원한다고 단정하지 않는다.

`python -m ultralytics`는 패키지의 실행 진입점 `__main__`이 없어 실패했고, Python의 `YOLO` API를 이용한 학습은 성공했다. 실패한 실행 요청 1회와 성공한 학습 1회를 구분했다. 설치·확인 명령과 실행 조건 예시는 [T02 Smoke Notes](../../training/experiments/t02-smoke/T02-smoke-notes.md)에 정리했다.

## 결과가 의미하는 것

환경 준비부터 GPU 학습, validation, checkpoint 저장까지 연결됐다는 뜻이다. 최종 validation은 4장/17개 객체에서 mAP50 약 0.616을 기록했지만, **COCO8 성능 숫자는 엔진 검사 정확도를 뜻하지 않는다.** 데이터가 매우 작고 대상도 실제 엔진과 다르기 때문이다.

이번에 바뀐 것은 ignore 규칙, 증거 로그, 학습 기록과 Task 상태다. 기존 모델·패키지는 그대로 보존했다. 필요한 증거가 이미 있으므로 재학습은 필요 없으며 이번 작업에서는 금지했다.

## V1에서 어떻게 재사용하는가

프로젝트 가상환경을 명시적으로 사용하는 습관과 환경→GPU 실행→validation→저장 파일을 확인하는 순서를 재사용한다. V0-T04부터 직접 촬영한 Proxy Dataset으로 워크플로를 연습하고, V1에서는 **실제 엔진 Dataset**과 클래스·모델·레시피·평가 데이터를 교체한다. 환경 smoke 통과와 실제 제품 성능 통과는 각각 별도 근거로 판단한다.
