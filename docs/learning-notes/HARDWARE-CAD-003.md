# HARDWARE-CAD-003 학습 기록

## 무엇을 했는가
CAD-002의300 mm 기둥·15 mm 간격·높이11단계를 유지하고 Deck을 길게 연장했다. Portal을 검사 영역 뒤쪽에 두어 지지 구조가 시야에서 빠지게 했다. 렌즈 창을 아래로 넓히고 Velcro와 Cable을 뒤쪽으로 배치했다.

## 왜 했는가
부품이 서로 충돌하지 않아도 카메라가 거치대 자체를 촬영할 수 있다. Vision 검사에서는 카메라의 광선이 지나는 공간도 비워야 한다. 처음 설계의 기계적 PASS는 새로 추가된 광학 요구의 PASS가 아니었다.

## 무엇을 관찰했는가
확정되지 않은 FOV90°/70°와 동공 위치를 가설로 정하고, 측면 법선 방향5 mm 여유를 포함한 공간을 검사한다. 실제 STL 삼각형을 이 공간으로 잘라 교차를 찾으며, 공간이 부품 안에 통째로 들어간 경우도 검사한다. 정점이 하나도 안에 없더라도 넓은 면이 시야를 가로지를 수 있으므로 정점 검사만으로는 충분하지 않다.

## 결과가 의미하는 것
최종 전체 재생성에서8개 STL mesh, 33개 자세의429개 광학 교차 검사, 교차 알고리즘7개 테스트가 통과했다. 이는 정해 둔 조건 안의 디지털 검증 결과다.
최종 실행 결과는 V3 `validation/stl_validation.json`의 `optical_fov`에 기록한다. 큰 FOV 가정은 거치대가 시야에 들어오는지 검사할 때는 보수적이지만, Belt 전체를 볼 수 있는지 계산할 때는 낙관적이다. 실제 카메라가 그보다 좁거나 동공 위치가 다르면 결과가 달라진다. 실제 영상·강성·진동·PETG creep은 따로 확인해야 한다.

## V1에서 어떻게 재사용하는가
실제 HFOV/VFOV와 Lens 중심을 측정한 뒤 parameter를 바꾸고 같은 검사기를 다시 실행한다. Height index와 slide 위치를 기록해 촬영 조건을 재현한다. 모델 정확도 이전에 거치대·케이블·체결부가 관측 영역을 가리지 않는지 확인하는 절차를 재사용한다.
