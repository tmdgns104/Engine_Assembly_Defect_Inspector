방향과 부품 자리

긴 금색 축 끝이 아래, 짧은 끝이 위인 자세가 0°입니다. 좌·우 파이프는 화면의 좌우가 아니라 엔진 기준의 고정 자리입니다.

ORB/RANSAC의 reference→raw 변환 M을 저장하고 역변환으로 본체를 정렬했습니다. V8 본체 표식의 방향 일치도(NCC)가 0.35 미만이면 결과를 사용하지 않았습니다.

부품 상태에 따라 영역 위치·크기를 바꾸지 않았습니다. 결품도 같은 자리를 보며 연결부와 오조립이 벗어날 여백을 포함합니다.

입력224의 의미

BGR 원본 → 본체 정렬 → 고정 영역 → 짧은 변에 회색40 패딩 → bilinear224 → RGB → 0~1 float32입니다. 종횡비를 보존합니다.

추가 RandomResizedCrop/CenterCrop, 반전, 회전, RandomErasing, 자동 증강은 모두 껐습니다. 저장 모델 재로딩 후에도 같은 기본 입력 텐서인지 확인했습니다.

촬영 안내 각도·guide ROI·정답 상태는 정렬 함수 입력으로 사용하지 않았습니다.

원본·정렬 사진은 보기용 축소 JPEG입니다. 네 부품 PNG는 실험에 사용한 파일을 그대로 표시합니다. 색 테두리는 고정 검사영역 설명이며 새 bbox 정답이 아닙니다. 정답 라벨과 예측은 수정할 수 없습니다.

03 / HOW WE SCORED

무엇을 맞혔는지,
분모까지 확인합니다.

정렬 실패나 출력 누락은 모델 혼동행렬에 넣지 않습니다. 대신 전체 155장 대비 처리율을 별도로 표시합니다.

혼동행렬

행 = 검토 정답 · 열 = 모델 예측. 대각선은 일치, 그 외 칸은 오분류입니다. 숫자를 누르면 해당 사진을 탐색할 수 있습니다.

정밀도·재현율·F1 계산

각 클래스를 “이 상태 / 나머지 상태”로 나눠 계산합니다. macro F1은 모든 클래스의 F1을 같은 비중으로 평균합니다. top-5는 사용하지 않습니다.

클래스별 표본과 성능

100% 분류 결과는 155장 전체의 검사 성공률이 아닙니다.성공한 부품 crop에서만 1.000이 나왔습니다. 네 부품을 모두 처리한 사진은 110/155장이고, 나머지 45장에는 전체 판정을 내리지 않았습니다.
04 / TRAINING TRACE

학습 중 무엇을 보고 모델을 골랐나요?

실제 epoch 로그입니다. 학습 loss는 학습 데이터에서, macro F1은 개발검증 데이터에서 계산했습니다.

학습 loss

낮을수록 학습 표본에 대한 오차가 작습니다. 이것만으로 검증 성능을 주장하지 않습니다.

개발검증 macro F1

높을수록 좋습니다. 이 값이 가장 높은 best 체크포인트를 선택했습니다. 동률에는 마지막 동률 모델이 저장됩니다.

실제 epoch 숫자와 실행 설정
학습과 검증의 역할이 다릅니다.TRAIN으로 가중치를 업데이트하고, VALIDATION으로 epoch별 성능을 확인해 best를 골랐습니다. 이 보고서의 결과는 best를 새로 불러와 예측한 결과입니다. 60 epoch 상한·patience10의 조기종료로 실제 실행 횟수는 부품마다 다릅니다.
